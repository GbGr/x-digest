# x-digest — сырьё для ежедневного AI-дайджеста ленты X

Этот репозиторий — «нижняя половина» пайплайна. Каждое утро в 10:07 по Сайгону
GitHub Actions забирает свежие посты 30 подписок через twitterapi.io и кладёт их
в `data/`. «Верхняя половина» — ежедневная задача Claude (Cowork), которая в 11:00
читает эти данные, отбирает полезное по рубрике и к ~11:30 кладёт готовый дайджест
на русском в проект «AI Insights & News» + шлёт push-уведомление.

```
GitHub Actions (10:07) ──> data/feed/<дата>/part-*.md ──> Claude scheduled (11:00)
      twitterapi.io              этот репозиторий            дайджест в проекте
```

## Установка (один раз, ~5 минут)

1. **Создай публичный репозиторий** с именем `x-digest` на GitHub и залей в него
   содержимое этой папки (важно: репозиторий должен быть публичным — Claude читает
   данные по raw-ссылкам без авторизации; в данных только публичные твиты).

   ```bash
   cd x-digest
   git init -b main && git add -A && git commit -m "init"
   git remote add origin https://github.com/<ТВОЙ_USERNAME>/x-digest.git
   git push -u origin main
   ```

2. **Добавь секрет с ключом API.** Repo → Settings → Secrets and variables →
   Actions → New repository secret: имя `TWITTERAPI_KEY`, значение — твой ключ
   twitterapi.io. Через gh CLI: `gh secret set TWITTERAPI_KEY`.
   ⚠️ Ключ живёт только в секретах — не вписывай его в файлы репозитория.

3. **Прогони workflow вручную.** Вкладка Actions → `x-feed-fetch` → Run workflow.
   Через ~1–2 минуты в `data/feed/<сегодня>/` появятся `index.md` и `part-*.md`.

4. **Скажи Claude свой username** — он пропишет URL репозитория в конфиг проекта
   (`claude/digest-config.md`) и соберёт первый дайджест.

## Как это менять

- **Список аккаунтов** — `accounts.txt`, по одному хэндлу в строке (без @).
- **Окно выборки** — env `WINDOW_HOURS` в workflow (по умолчанию 26 часов).
- **Расписание** — cron в `.github/workflows/fetch.yml` (UTC! 03:07 UTC = 10:07 Сайгон).
- **Рубрика отбора и формат дайджеста** — не здесь, а в документе проекта Claude
  `claude/digest-rubric.md` (правится словами, без кода).

## Что где лежит

- `data/feed/<дата>/index.md` — сводка: когда собрано, сколько элементов, сколько частей.
- `data/feed/<дата>/part-NN.md` — компактные блоки твитов (треды уже склеены,
  реплаи чужим и дубли ретвитов выброшены).
- `data/feed/latest/` — копия последнего дня под стабильным путём.
- `data/latest.json`, `data/archive/<дата>.json` — полные данные в JSON.

## Стоимость и надёжность

- twitterapi.io: ~$0.15 за 1000 твитов; при 30 аккаунтах это обычно **$2–5/мес**.
  Следи за балансом на twitterapi.io — при нуле ран станет красным.
- GitHub Actions: бесплатно (несколько минут в день).
- Если ран красный: чаще всего кончился баланс ключа или twitterapi.io лежит.
  Утренняя задача Claude заметит несвежие данные и напишет об этом в дайджесте.
- Смена провайдера данных (socialdata.tools, Apify, twscrape) меняет только
  `fetch_tweets.py` — формат `data/` и вся верхняя половина остаются как есть.

## Самопроверка без сети

```bash
TWITTERAPI_SELFTEST=1 python fetch_tweets.py
```
Сгенерирует тестовые данные и покажет, что скрипт собирает файлы правильно.
