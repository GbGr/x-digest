“A normal LLM/harness puts the data into the model’s context and lets the model reason over it. An RLM keeps the data outside the model and lets the model write a program that computes over it, using LLM calls themselves as one of the program’s primitives”

In any case, came away after listening with a desire to try out Prime Agents, or experiment with building a ‘RLM-centric’ environment using something like Pi
