I recently set up a second Mac mini (a Tahoe machine for backwards compatibility of my CLIs) and Codex Remote voice mode guided me through the process of setting up a Comet Remote KVM while I was wearing AirPods. (Pictured: a Linux Mini PC Codex also set up for me.)

(My second favorite as an iOS user: T3 Code on iOS by @theo and team. Super smooth onboarding flow with T3 Connect and I love the multi-harness nature of it. Wish it had a voice mode!)

Some wishes for Codex Remote:

- Home Screen widgets to launch Codex Remote and its voice mode 
- Proper integrations with iOS frameworks (Reminders, Calendar, etc.)
- Integration with Files app (mount local iOS folders)

Overall, probably my favorite iOS feature in a long time. Nothing else quite like it right now.
